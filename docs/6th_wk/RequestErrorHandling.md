# 요청 상태별 오류 처리

## 개요

채팅, 음성 인식(STT), 음성 합성(TTS) 요청 실패를 하나의 문구로 표시하던 방식을 상태별 안내로 변경했다. 다시 처리할 수 있는 오류에는 `다시 시도` 버튼을 제공하며, 성공하면 기존 대화를 그대로 이어간다.

## 상태별 의미

| 상태 | 발생 상황 및 문제 | 사용자 안내 | 다시 시도 |
| --- | --- | --- | --- |
| 429 | 짧은 시간에 요청이 너무 많거나 외부 API 사용 한도에 도달함 | 요청이 잠시 제한됐어요 | 채팅은 가능, 음성 한도 초과 시 텍스트 모드 전환 |
| 503 | Gemini 또는 배포 서버가 과부하·점검 등으로 일시적으로 요청을 처리하지 못함 | AI가 잠시 바빠요 | 가능 |
| 408·504·클라이언트 타임아웃 | 서버 응답이 앱의 제한 시간인 20초 안에 도착하지 않음 | 응답 시간이 길어지고 있어요 | 가능 |
| 네트워크 오류 | 인터넷 연결이 끊겼거나 브라우저가 서버에 연결하지 못함 | 인터넷 연결을 확인해주세요 | 가능 |
| 500 이상 | 백엔드, Gemini 연동 또는 DB 처리 중 예상하지 못한 서버 오류 발생 | 서버에서 문제가 발생했어요 | 가능 |
| 401·403 | 로그인 만료 또는 요청 권한 없음 | 인증을 확인해주세요 | 불가 |
| 404 | 세션이 삭제됐거나 존재하지 않음 | 대화를 찾을 수 없어요 | 불가 |
| 기타 | 상태를 특정할 수 없는 일시적 오류 | 응답을 받아오지 못했어요 | 가능 |

## 재시도 동작

- 채팅 실패: 화면에 이미 표시한 사용자 메시지는 중복 추가하지 않고 AI 응답 요청만 다시 전송
- AI 답변 생성이 성공한 뒤 메시지를 DB에 저장해 503 재시도 시 같은 사용자 메시지가 중복 저장되는 문제를 줄임
- STT 실패: 보관한 녹음 Blob을 다시 변환·전송하므로 사용자가 같은 말을 다시 녹음할 필요 없음
- TTS 실패: 이미 받은 텍스트 답변은 유지하고 음성 합성·재생만 다시 요청
- 닫기: 오류 안내를 닫고 음성 사용이 가능하면 듣기 상태로 복귀

## 백엔드 변경

외부 AI가 반환한 503을 공통 500 오류로 바꾸지 않고 클라이언트까지 그대로 전달한다.

```json
{
  "message": "AI 서비스가 일시적으로 요청을 처리할 수 없습니다. 잠시 후 다시 시도해주세요."
}
```

관련 파일:

- `backend/src/middleware/errorHandler.js`
- `front/src/requestError.js`
- `front/src/AirPodsLog.jsx`
- `front/src/AirPodsLog.css`
