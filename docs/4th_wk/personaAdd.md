# 페르소나 분류, 소비자 입장에서 생각해보기

## 지금 구조의 문제
현재 4개 페르소나(운동 중 / 자기 전 / 공부 중 / 일반 대화)를 보면, 사실 서로 다른 두 가지 기준이 섞여 있다.

- **운동 중 / 자기 전** → "지금 뭘 하고 있는가" (상황·활동 기준)
- **공부 중 / 일반 대화** → "지금 무슨 목적으로 대화하는가" (모드·목적 기준)

기준이 섞여 있으면 사용자가 "내 지금 상황에 맞는 페르소나가 뭐지?"를 고를 때 헷갈릴 수 있다. 소비자는 보통 "나 지금 이거 하고 있어"라는 상황으로 진입하지, "나 지금 어떤 대화 모드로 들어가고 싶어"라고 생각하며 앱을 열지 않는다. 그래서 축을 하나로 통일하는 게 먼저라고 본다.

## 내가 소비자라면 실제로 쓸 상황들

음성 전용 앱의 핵심 가치는 "손과 눈이 자유롭지 못한 순간"에 있다. 그 기준으로 우선순위를 매겨봤다.

### 1순위 — 손/눈이 진짜로 막혀 있는 상황 (음성 앱의 존재 이유)
- **이동 중 (통학/통근, 버스·지하철·도보)** — 화면을 볼 수 없거나 보기 귀찮은 가장 대표적인 순간. 대학생 타겟이면 하루 중 빈도가 꽤 높을 것.
- **운동 중** (기존 유지) — 동일한 이유로 이미 잘 잡혀 있는 페르소나.
- **요리 중 / 집안일 중** — 손이 막혀 있는 전형적 상황. 우선순위는 낮지만 스토리로는 설득력 있음.

### 2순위 — 심리적으로 "화면을 보고 싶지 않은" 상황 (스크린 피로 완화라는 프로젝트 취지에 직결)
- **자기 전** (기존 유지)
- **아침에 막 일어났을 때** — 자기 전과 대칭되는 페르소나. 알람 끄자마자 화면 보는 습관 자체가 스크린 피로의 큰 원인이라 프로젝트 메시지와 잘 맞는다.
- **시험 기간 스트레스 / 번아웃 순간** — 대학생 타겟에게 니즈가 클 것 같은 지점. 다만 감정을 다루는 페르소나라 톤 설계에 신중함이 필요.

### 3순위 — 목적 기반 (지금의 "공부 중"이 여기 속함)
- **공부 중 / 과제·집중 중** (기존 유지, 다만 "공부"보다 "몰입/집중"으로 넓히면 취준·코딩 등도 포괄 가능)
- **일반 대화** (기존 유지) — 특정 상황이 아니라 기본값(default) 역할이라 계속 필요.

## 결론: 내가 제안하는 구조

축을 억지로 통일하기보다, **"상황 기반 페르소나"와 "일반 대화(디폴트)"로 크게 나누고**, 그 안에서 상황들을 계속 추가해가는 방식이 소비자 입장에서 가장 직관적이라고 생각한다.

- 상황 기반: 운동 중, 자기 전, 아침 기상, 이동 중, (선택) 공부/집중 중
- 디폴트: 일반 대화

"공부 중"만 유일하게 목적 기반으로 남아있는 게 어색하다면, 이름을 "집중 모드"로 바꿔서 상황처럼 느껴지게 만드는 것도 방법이다 (예: "공부하다가 켰다"든 "일하다가 켰다"든 결국 "지금 집중해야 하는 상황"이라는 하나의 카테고리로 묶임).

## 추가 시 impact-to-effort 우선순위
1. **이동 중** — 니즈 큼, 프롬프트 설계 단순, 빠르게 추가 가능
2. **아침 기상** — 자기 전과 대칭이라 스토리텔링과 데모 임팩트가 좋음
3. **시험 기간/스트레스 케어** — 니즈는 크지만 감정 다루는 페르소나라 신중한 설계 필요 (P1~P2 정도로 남겨두는 게 안전)
4. **요리 중 등 기타 상황** — 있으면 좋지만 우선순위는 낮음
