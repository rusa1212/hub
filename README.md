# 🎧 에어팟 로그 (AirPods Log)

### 화면 피로도가 높은 대학생들을 위한 실시간 맥락 맞춤형 오디오 에이전트 서비스

---

## 📌 1. 기획 배경 (Problem Discovery)

- **캠퍼스 내 높은 무선 이어폰 착용률**: 대학생들의 캠퍼스 내 무선 이어폰(에어팟 등) 상시 착용 비율이 매우 높으며, 혼밥이나 홀로 이동하는 1인 중심의 생활 패턴이 보편화되었습니다.
- **시각 매체 및 기존 플랫폼의 피로감**: 에브리타임, 인스타그램 등 주류 커뮤니티는 텍스트와 이미지 중심의 시각 매체 구조로 스마트폰 화면 주시에 따른 피로감이 큽니다. 또한, 타인과의 감정 소모나 조롱, 과시성 게시글로 인해 일상 스트레스를 편하게 대출할 공간이 부족합니다.
- **새로운 오디오 UX 니즈 발생**: 이동 중이거나 휴식 시 스마트폰 화면을 보지 않고(Screen-free), 청각(오디오) 채널만을 활용하여 즉각적이고 가볍게 스트레스를 케어받고자 하는 잠재적 수요가 존재합니다.

---

## 📌 2. 문제 정의 (Problem Definition)

> 대학생들이 이동이나 휴식 시 무선 이어폰을 상시 착용함에도 불구하고, 폰 화면을 주시하지 않고 개인의 실시간 일상 스트레스를 즉각 해소할 수 있는 오디오 중심의 맞춤형 인터랙티브 콘텐츠 플랫폼이 부재하다.
> 

---

## 📌 3. 주요 기능 및 솔루션 (Core Features)

사용자가 폰 화면에 자신의 실시간 감정이나 현재 처한 상황을 텍스트로 가볍게 입력하면, AI 에이전트가 오디오 기반의 개인화된 피드백을 에어팟으로 즉각 송출합니다.

- **실시간 맥락 맞춤형 스크립트 생성**: 사용자의 입력값(예: "캡스톤 발표 전 극심한 긴장감", "과제 누적으로 인한 무기력함")을 LLM이 분석하여 최적의 페르소나와 대본을 실시간 빌딩합니다.
- **고품질 오디오 에이전트 출력**: 텍스트가 아닌 음성 기반 데이터 출력을 통해 사용자의 에어팟으로 현장감 있고 감정이 입혀진 고품질 TTS 음성을 스트리밍합니다.
- **상황 맞춤 오디오 연출 (BGM 매칭)**: 감정/상황을 몇 가지 카테고리(긴장, 무기력, 설렘, 분노 등)로 분류하고, 카테고리별로 사전 큐레이션된 BGM을 매칭하여 목소리와 함께 믹싱합니다.
    - *(MVP 단계에서는 실시간 AI 판단 믹싱 대신, 카테고리-BGM 매핑 테이블 방식으로 구현 난이도와 레이턴시를 낮춥니다. 정교한 실시간 믹싱은 고도화 단계에서 검토합니다.)*

---

## 📌 4. 기술 스택 및 아키텍처 (Technical Stack)

- **Frontend**: React (Vite), Web Audio API
- **LLM & Audio Engine**: OpenAI GPT-4o Audio API / Google Gemini API (Text-to-Audio Multimodal Output)
- **Voice Synthesis**: ElevenLabs API / Web Speech API (SpeechSynthesis)

- 🔄 대화형 워크플로우 (Conversation Flow)

### ⚠️ 기술적 리스크 및 대응

- **레이턴시**: 실시간 Text-to-Audio 생성 API는 응답 지연이 발생할 수 있어, "즉각 송출" UX와 실제 속도 간 괴리가 생길 수 있음 → 로딩 인터랙션(짧은 효과음/멘트) 설계로 체감 대기 시간 완화
- **BGM 믹싱 복잡도**: 실시간 AI 믹싱은 난이도가 높아 MVP에서는 카테고리 매칭 방식으로 단순화 (위 3번 참고)

## 📌 5. 데이터 및 프라이버시 정책 (Privacy & Data Policy)

감정/스트레스 관련 민감 데이터를 다루는 서비스이므로, 초기 설계 단계부터 아래 원칙을 적용합니다.

- **익명성 우선**: 사용자 계정과 감정 입력 데이터를 직접 연결하지 않고, 세션 단위로만 처리 (비로그인 사용 가능 구조 검토)
- **최소 보관 원칙**: 입력된 텍스트/생성된 오디오는 서비스 제공 목적 외 저장하지 않으며, 일정 시간 후 자동 삭제 (예: 세션 종료 시 또는 24시간 내)
- **명시적 동의**: 데이터 분석·서비스 개선 목적으로 활용 시 별도 동의 절차 마련
- **민감 콘텐츠 필터링**: 자해, 심각한 정신건강 위기 등의 입력이 감지될 경우, 일반 페르소나 응답 대신 전문기관 안내로 전환하는 안전장치 마련
- *(추후 "공간 기반 익명 아카이빙"으로 확장 시, 위치 데이터와 감정 데이터가 결합되므로 프라이버시 정책을 별도로 강화 검토 필요)*

---

## 📌 6. 추후 확장성 (Scalability Roadmap)

기존 확장 아이디어(로컬 광고, 공간 기반 아카이빙)는 장기 비전으로 유지하되, 그 사이 현실적으로 검증 가능한 단계를 추가했습니다.

### Phase 1 — MVP 이후 단기 (핵심 경험 강화)

- 페르소나/BGM 카테고리 다양화 및 사용자 선호 학습 (즐겨찾는 페르소나 저장)
- 감정 기록 요약 리포트 (예: "이번 주 가장 많이 느낀 감정" 통계, 텍스트 기반, 비저장형)
- 카카오톡/링크 공유 기능으로 자연 유입 확대

### Phase 2 — 중기 (커뮤니티/개인화 고도화)

- 실시간 BGM 믹싱 고도화 (AI 기반 다이나믹 믹싱)
- 학교별 특화 페르소나/콘텐츠 (학교 밈, 은어 반영)
- 캠퍼스 앱/커뮤니티(에브리타임 등)와의 연동 또는 위젯 형태 제공

### Phase 3 — 장기 비전

- **오디오 마케팅 플랫폼 (B2B)**: 캠퍼스 GPS 동선과 연동하여 주변 소상공인 이벤트/쿠폰을 오디오 사연 형태로 결합하는 로컬 광고 모델
- **공간 기반 익명 아카이빙**: 특정 강의실·좌석 등에 익명 오디오 발자국을 남기고 공유하는 공간 기반 오디오 SNS로 확장
    - *(단, 위치 데이터 결합 시 프라이버시 리스크가 커지므로 별도 법적 검토 및 안전장치 선행 필요)*
